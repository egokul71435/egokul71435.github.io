Projects

02
edge-moe: MoE Language Models on Apple Silicon
In progress
A custom mixture-of-experts decoder-only transformer in PyTorch, optimized for M-series Macs. Top-k expert routing with loss-free load balancing to keep compute units utilized and cut inference latency across experts. GQA and RoPE reduce KV-cache memory bandwidth; weight tying across the token embeddings and output projection shrinks the memory footprint and parameter count. Fed by a custom Rust BPE tokenizer (50k vocab, ~570M tokens of FineWeb-edu) with PyO3 bindings, and benchmarked across PyTorch MPS vs MLX backends.
github ↗ PyTorch MPS MLX Rust PyO3 MoE GQA RoPE
Chain-of-Thought Knowledge Distillation
Completed
A CoT distillation pipeline in PyTorch doing both sequence- and logit-level KD, with cross-tokenizer alignment via character-offset tracking, distilling 70B+ parameter teachers (Llama 3.3, GPT-OSS) into a Llama 3.2 3B student. The interesting result was a correctness-vs-style tradeoff between the two objectives: logit KD beat the baseline by 29% on task performance, while sequence KD gave the closest teacher replication at a 0.9693 BERTScore F1 across SciBench and TheoremQA.
